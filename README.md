# Credit Risk & Client Data Analysis

Пет-проект по анализу данных банковских клиентов и оценке кредитного риска с использованием Python.

## Задачи проекта
- Очистка и предобработка табличных данных (работа с пропусками, дубликатами и выбросами)
- Исследовательский анализ данных (EDA): выявление факторов, влияющих на возврат кредита
- Расчёт ключевых метрик по возрастным группам, уровню дохода и кредитной нагрузке
- Построение базовой модели классификации для оценки вероятности дефолта

## Стек технологий
- **Язык:** Python
- **Анализ данных:** Pandas, NumPy
- **Машинное обучение:** Scikit-learn
- **Базы данных:** SQL / SQLite
